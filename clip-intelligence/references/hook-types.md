# Hook Types

Use the hook that matches the opportunity instead of forcing every clip into a joke/punchline structure.

- **Comedy hook:** setup, contradiction, reaction, punchline.
- **Personality hook:** strong opinion, preference, unusual behavior, creator-specific rule.
- **Progression hook:** what changed, what was unlocked, what happens next.
- **Curiosity hook:** unexplained event, question, mystery, incomplete information.
- **Story hook:** conflict, discovery, escalation, consequence.
- **Community hook:** choice, disagreement, competition, audience vote, debate.
- **Discovery hook:** surprising fact, useful trick, unexpected mechanic, new information.

A strong hook should be understandable with the smallest practical amount of setup. Do not fabricate wording that the creator did not say; suggested hooks should summarize or select from available source language.
