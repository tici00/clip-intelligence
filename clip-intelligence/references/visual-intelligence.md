# Visual Intelligence

When video is available, inspect the visual evidence before assigning Visual/Edit Potential.

Look for:

- visible reactions and facial expressions
- gameplay state changes, unlocks, rewards, failures, discoveries
- UI or scene changes that clarify the event
- objects entering, leaving, or changing state
- readable on-screen information when it is genuinely visible
- framing and composition that support a vertical short
- moments where a cut, zoom, caption, freeze frame, or replay would improve clarity

Do not infer a visual event solely because the transcript suggests it happened. If the video is unavailable or cannot be inspected reliably, state that limitation and lower confidence.

Visual evidence should strengthen the content decision, not replace it. A visually busy moment with weak content should not automatically rank highly.
